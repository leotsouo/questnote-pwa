# 劍隱山河專屬演出

依使用者「動畫不要沿用」要求，以本地 CSS／SVG 製作新場景；沿用穩定的交易與揭露佇列控制介面。新主題鍵為 `swordwild_shanhe`，三 UR 揭露鍵為 `sword_eagle`／`sword_toad`／`sword_ape`。沒有生成或替換已核准第三版卡圖。

## 山河啟卷：卡池入場

雲霧退向兩側，遠近群山浮現，卷軸展開；古道金線越過石橋，中央一枚「俠」印回應。一諾入山、百川同行，最後落在「劍隱山河」。墨綠、竹青與舊金維持孤高而溫暖的山河氣氛。

使用者於動畫檢視後修訂：印記僅保留「俠」，移除「諾」及「心」。此為來源演出的視覺修訂，覆蓋既有凍結企劃的三印分鏡敘述；角色、卡圖與候選內容 bytes 未變。歷史候選與核准紀錄保持原樣，發布使用新來源重建產物。

完整入場 3.4 秒後可繼續；切換卡池的短轉場 0.9 秒。隨時可略過。減少動態使用靜態群山與印記，移除位移和放大。

## 劍光赴約：抽獎

雲霧聚攏 → 紙卷與古道打開 → 劍光掠過、俠義印記亮起 → 雲幕分開，夥伴赴約。單抽前奏 N 2.3、R 2.4、SR 2.55、SSR 2.75、UR 3.3 秒；十連增加 0.2 秒。減少動態前奏總共 0.52 秒。

| 稀有度 | 光色與揭露 |
| --- | --- |
| N | 淡竹綠，古道上的普通夥伴 |
| R | 霧藍，印記呼應 |
| SR | 淡紫，劍光增強 |
| SSR | 金墨劍痕與山河紙卷，1.5 秒揭露 |
| UR | 丹金，以下三種角色專屬演出，各 2.6 秒 |

| UR | 故事、卡圖與動作的關聯 |
| --- | --- |
| 玄翎重岳雕 | 巨翼從兩側張開並掃退霧幕，接上已核准的展翼卡圖；以高處俯臨山河的姿態呈現霸主感。 |
| 丹砂鎮嶺蛤 | 朱息界線在腳下展成雙圈後定住山嶺，呈現坐鎮一方；保留蛤的形貌，沒有加入龜殼或玄武混合構造。 |
| 素心劍猿 | 斜向劍光沿劍勢切開竹葉軌跡，接上直劍卡圖，使名字、劍元素與動作一致。 |

減少動態 SSR 0.55、UR 0.75 秒，以靜態獸印、卡圖和字幕展示。十連按實際結果順序逐隻揭露 SSR／UR，包含同一角色重複出現；Enter 繼續，Escape 略過剩餘演出。前奏略過、圖片載入失敗、快速連點與關閉仍走既有保護路徑。
