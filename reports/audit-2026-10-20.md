## 防護機制（新增）

- `npm run lint`：ESLint 9 最小規則（`no-undef`、`no-dupe-keys`、`no-const-assign`、`no-unreachable` 等）跨 `src/`、`service-worker.js`、`devtools/`、`scripts/`、`backend/`；就是「找不到變數」這類錯誤的靜態擋板。`src/` 目前 0 errors、23 warnings（未使用變數）。
- `node devtools/syntax-check.mjs`：`node --check` 掃 140 個 runtime 檔。
- `npm run check`：lint → 語法 → `npm test` → `pools:validate` → `images:check`，一鍵完整檢查；CI（`.github/workflows/validate.yml`）加了相同的 lint 與語法步驟。
- `src/errorLog.js`：記錄本次 session 的未捕捉錯誤與 unhandled rejection（訊息、檔案:行、堆疊、版本），設定頁版本卡顯示「最近錯誤」，回報表單「環境資訊」帶最後 5 筆。`devtools/error-log.test.mjs`。
- `.claude/launch.json` 加 `e2e-flows`（8765）、`e2e-final-user`（8766）兩個隔離伺服器，真實 UI 端對端頁面一鍵啟動。
- `CLAUDE.md` 新增「新功能與更新檢查清單」。
