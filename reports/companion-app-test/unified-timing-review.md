# 六池共同演出時間 · V3.5.16

日期：2026-10-03。來源分支 codex/companion-app-art-test，前版 44cd234／V3.5.15。本機完整 App：<http://127.0.0.1:4193/>。記憶體展示資料，重新整理重設；未合併、push 或發布。

## 修正

使用者要求所有卡池的演出時間與逆造之誓一致。前版只有新版身份交接的 SSR 2.5 秒／UR 4.5 秒一致；前奏仍依主題、抽取模式與稀有度分配不同時間，非獅心城完整入場 3.4 秒／再訪 .9 秒，原生角色也還有 SSR 1.5 秒與 UR 2.2–2.8 秒的舊值。

新增 `src/summonTiming.js` 作為共同時間來源，控制器、既有模板 API、原生 reveal 與新版 identity 皆使用它：完整入場 6000ms，再訪 1500ms；前奏 650／750／900／700ms，合計 3000ms；SSR 2500ms、UR 4500ms；下一位 240ms。正常單抽與十連前奏不再依稀有度延長。每張身份揭露及等待點擊仍沿用前版，因此十連總觀看時間會隨 SSR／UR 張數與使用者停留不同。

地景保留各池美術與分鏡，控制器供應場景時間變數；日出、山河移動、旅門與花海核心動作在時間窗口內完成，避免只延長計時器或把 CSS 動作截斷。非獅心城卡面動作也使用同一個角色時間變數，62% 到位後停留。逆造之誓原有專屬風／蒸汽演出保留。

減少動態入場 500ms，前奏 500ms；原生 SSR 550ms／UR 750ms，本機新版減少動態可直接結果，十連直接總覽。檢查時發現繼續提示仍有 .45 秒文字位移，已移除；最終六池減少動態沒有活動動畫。載圖失敗的短 fallback 保留並明確區分，不以故障替代畫面冒充正常演出通過。

六池再訪 1506–1511ms，設定皆 1500；最終減少動態 508–516ms，設定皆 500，無活動動畫。六池 UR 卡面 computed duration 4.5s；劍隱山河下一位淡出 computed transition .24s。每池由 SSR 依序前進 UR，再到完整十張總覽，沒有跳人或卡住。

另驗證劍隱山河正常單次前奏／UR、前奏 Escape 略過完整十連、減少動態直接十連總覽、三套 Theme 的 320px／200% 字級、鍵盤 Tab 焦點及 Escape 返回。詳細測量與最終單次、略過紀錄見 [unified-timing-browser-qa.json](unified-timing-browser-qa.json)。單抽／十連與各稀有度的時間 contract 另由 Node tests 驗證，不把單一案例當作所有角色都逐隻看過。
