# 終點今天不想上班 — 本機試作

選用十秒「終點逃跑」小劇場，已接入每日賽事 controller，也提供 `devtools/race-theatre.html` 無限次觀賞頁，共用 `dailyRaceScene.js` 與 App 樣式。試玩頁不呼叫賽事、星塵或 IndexedDB API；同組重播維持同一勝者，換組後再抽新展示勝者。

演出依序為起跑、终點逃跑、全員傻眼、追趕換位、工作人員抓捕、衝線定格。App 仍以交易已保存的 winnerId 驅動演出，略過或關閉會取消 RAF；減少動態沿用 App 直接呈現賽果，試玩頁另外提供靜態衝線畫面。

驗證：

- 完整 `npm test` 通過，相關賽事／動畫檢查 9/9 通過。
- 新動畫逐一測試四種勝者、每種 1,001 個時間點，只有已指定勝者越過終點；四位角色均有領先時刻。
- 新增及修改 JS 語法檢查、`git diff --check` 通過。
- Codex 右側瀏覽器實際開始、自然結束、重播、略過、減少動態定格通過；390×844 畫面無水平溢出，瀏覽器無 error logs。
- 試玩 server 為隔離 localhost origin；正式站與既有存檔未用於此次驗收。未執行正式不可變產物組裝、發布或實體手機驗收。

本機分支 `codex/race-runaway-finish`，來源版本預備為 V3.9.3，SW cache 及新模組 precache 已同步。此文件代表試作驗收，不代表正式 V3.9.3 已發布。

## 第二版：活著的終點線

依試玩回饋改為 30 秒、六段播報各停留 5 秒，播報移到賽道上方。每條終點標記加上一顆會眨眼、轉動瞳孔的眼睛；終點反覆前進與回頭。移除工作人員、抓捕與拍照定格演出，結束後直接呈現一般賽果。

第二版 targeted tests 10/10 通過，包含四種勝者在完整時間軸中不被其他選手搶先越線、播報停留時間及終點多次變換方向。修改的 JS 語法與 diff 檢查通過。右側實際重新載入第二版，390×844 截圖確認眼睛、上方播報及四條賽道呈現。

## 四種劇本版：每場 20 秒

使用者通過第二版後指定縮短至 20 秒、活眼終點只保留眼睛造型，並加入正常賽跑和另兩種劇本。本版提供 `normal` 正常競速、`living-finish` 活眼終點、`nap` 領先者打瞌睡、`wrong-way` 全員跑錯方向。五段播報各保留 4 秒。

App 開始動畫時使用獨立的 Web Crypto 隨機 byte 選劇本，四種各 25%，選劇本不接收下注或賽果作為隨機輸入；動畫接收既有已結算 winnerId。沒有改寫 META 存檔或結算。試玩頁增加四劇本／隨機選單，同場重播保留劇本與冠軍，換一場會重抽。活眼終點移除旗子、條紋身體與腿，只保留會眨眼的單眼。

驗證：完整 `npm test` 通過；targeted tests 11/11。逐一檢查 4 劇本 × 4 勝者 × 1,001 時點，只有指定勝者越線；均勻 256 種 byte 各分配 64 次；各播報 4 秒；睡覺選手停跑、全員反向跑動、固定終點與活眼來回移動均符合預期。修改的 JS 語法與 diff 檢查通過。

右側瀏覽器實際選擇四種劇本，觀察 Zzz／四位反向狀態；正常略過、睡覺自然結束、隨機選擇及減少動態重播一致通過。390×844 活眼畫面確認只剩眼睛且無水平溢出，瀏覽器 error logs 為空。預览留在隨機四選一入口。仍為本機未發布試作。
