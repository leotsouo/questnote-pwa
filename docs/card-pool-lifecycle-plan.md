# 卡池生命週期改善計畫

基準：2026-10-10 的《QUESTNOTE 卡池生命週期規劃報告 v1.0》。每階段獨立驗證及提交，完成代表流程後再擴展。來源提交不等於正式發布。

## 分階段順序

1. **探索入口與常設系列畫廊（已完成）**：固定高度的橫向封面列，直接點圖切換卡池；「全部系列」開啟圖像畫廊。依使用者對第一版的回饋，搜尋改為收合的輔助功能，選池不需輸入文字。保留目前選池與原有取得規則。
2. **推薦期與時間告知（本次）**：實作推薦日期、倒數及到期行為；使用者已確認首次正式日期尚未確定，保留至發布前設定。一般系列持續開放，推薦結束不重設保底或關閉歷代系列。
3. **指定取得經濟試算**：先驗證 14 天參與情境、指定 SSR／UR 成本、穩定相遇碎片來源及跨期方式，再決定是否承諾每期取得一位。
4. **發布與維護流程**：建立 14 天目標排程、內容儲備與三週期觀察；依品質及取得體驗調整每池規模。總池擴編、共享保底與特殊系列期限另行定案。

## 第一階段邊界

- 先完成召喚頁這一個代表畫面：大幅角色插畫、直接選池、圖像畫廊；圖鑑沿用原有系列篩選。
- 啟動時不再強制重設為星旅之原，保留使用者已儲存的系列選擇；沒有選擇的新帳號仍以星旅之原開始。失效 ID 沿用既有 active pool resolver 的回退規則。
- 只展示 active 系列，不新增角色、不修改資料目錄、價格、候選、解鎖、保底或存檔結構。
- 最新登場由 `src/poolDirectory.js` 的 `POOL_NAVIGATION.featuredPoolId` 明確指定；整合目前主線後為霓霞仙膳。不從目錄順序或猜測日期判斷新池。
- 下次新系列通過正式發布流程時，需同步更新推薦 ID。若推薦 ID 缺席或停用，不顯示新登場標記，不替換成任意系列。封面列依序為最新、星旅之原、其餘 active 系列；系列增長不增加頁面高度。
- 搜尋只影響目錄可見項目，不影響抽卡名單與機率；永眠花海的角色數遵守原有解鎖狀態。
- 一般系列顯示持續開放，不使用「最後取得機會」文案。真正限時系列仍需先定義獨立政策。

## 驗證與交付

- 邏輯檢查：active 系列完整性、明確推薦、搜尋與花海解鎖候選。
- 隔離瀏覽器：不輸入文字即可選到所有系列、畫廊不自動聚焦搜尋、橫向封面列與選池持久化、抽取中禁止切池、手機與大字級、主題、鍵盤及離線入口。
- 依專案規範執行維護中的整合測試與 JS 語法檢查；版本與 SW 快取閉包同步。
- 本階段提交後保留本機功能分支供 review；不自動 push、發布或部署。

## 第二階段：推薦期與倒數

### 本次決定

- 推薦期目標 14 天；起點為本功能正式上線的生效時間，不回推霓霞仙膳先前發布時間。
- 2026-10-10 使用者選擇「日期尚未確定，發布前設定」，因此 `POOL_NAVIGATION.recommendation` 保持 `null`。玩家端延續最新系列與持續開放標示，不顯示假日期。
- 預覽測試日期只由隔離本機測試伺服器提供，不寫入來源排程、玩家存檔或正式站。

### 顯示與邊界

- `startsAt`、`endsAt` 必須為含時區的 ISO 時間。開始時間包含在推薦內，結束時間不包含；錯誤或不完整日期不啟用推薦倒數。
- 推薦中顯示「推薦期剩餘 X 天 Y 小時」；最後 24 小時顯示小時／分鐘，不顯示秒數，不讓讀屏每分鐘自動朗讀。
- 列出確切截止年月日、時間及「台灣時間 UTC+8」，並說明仍可在全部系列抽取、保底保留。
- 到期立即移除推薦標記，文字改為持續開放。為保留焦點和操作位置，不在計時更新時重建控制或移動畫廊；下一次正常重繪才讓星旅之原回到列首。
- 背景回到前景、頁面恢復與取得焦點時依目前時間重新計算；顯示期間最多每分鐘更新一次，若開始／結束邊界較近則準時更新。
- 到期不改寫選池、星塵、收藏、解鎖、候選或保底，不關閉正在播放的單抽／十連結果。
- 推薦採裝置時鐘及目前已載入的安排，離線可能無法取得新版排程；這是曝光資訊，不是限時獎勵或交易資格的可信時間。

### 正式啟用步驟

1. 在已核准發布包中確認首次上線時間，填入 `src/poolDirectory.js` 的 `POOL_NAVIGATION.recommendation = { startsAt, endsAt }`，結束時間原則上為開始後 14 天；同步核對 `featuredPoolId`。
2. 執行推薦期邏輯測試及隔離瀏覽器驗收，確認台灣日期、到期前後、選池持久化及單抽／十連結果。
3. 依原有版本、快取與不可變 artifact 流程形成正式包。正式上線時間變動時，先更新並重新驗證來源排程，再重新組包。
4. 推薦結束後一般系列留在全部系列；下一次安排新池時更新推薦 ID 與起訖，不用刪池或遷移存檔。
