# QuestNote Brand Voice

Campaign：**小事，有回音。** 現實中的小小完成，會在夥伴的回應、親密度和世界裡留下痕跡。產品核心是 Productivity × Companion × Fantasy × Growth。

以台灣繁體中文為先。溫暖、像真人、鼓勵、平靜，帶一點魔法。用具體日常和短句，不用提高效率百分比、不喊勇者、不誇大人生改造。夥伴陪著人前進，不用內疚或連續打卡壓力驅動。

| 情境 | 使用 | 避免 |
| --- | --- | --- |
| 完成 | 你的小事，牠收到了。 | 又征服一個史詩任務！ |
| 尚未完成 | 下一件小事，再一起完成。 | 你今天又沒有完成。 |
| 歡迎 | 今天想完成哪件事？ | 開啟最強人生！ |
| CTA | 開啟 QuestNote | 立即改變命運 |
| 成長 | 完成任務，累積你們的親密度。 | 解鎖無限潛力 |
| 資料提醒 | 換裝置前，記得匯出備份。 | 你的珍貴資料即將消失！ |

文案優先清楚，再有餘韻。產品名稱維持 QuestNote；在第一次使用「Quest」時說明是生活任務。親密度、星塵、冒險能量使用真實系統名稱；不創造 XP、成長天數或假實績。不要暗示一次完成就讓角色外觀進化。角色台詞只引用既有 Lore，行銷旁白另寫。既有 App 某些催促台詞不代表網站的新語氣標準。

字句審查：一位真人會這樣說嗎？是否講了具體的生活小事？是否讓人覺得自己可以從小處開始？是否正確描述現有功能？短句是否仍解釋清楚？標點使用全形中文；數字與英文以合理空隙混排。
