## 設計範圍

依來源 `61d7a139ad4f1225828b5633c9efdd7d2e39a4dd` 的覺醒 core、service、catalog 與演出設計；這是來源基準，不是部署證明。現有卡池名稱為「劍隱山河」，語音中的「劍影三合」沿用此正式名稱。

入口選定「圖鑑 → 劍隱山河角色詳情 → 羈絆覺醒」。卡池介紹只說明此養成並指向圖鑑，不另建操作入口。角色詳情未收藏也能查看準備步驟；此為展示範圍擴充，實際開始與儀式仍要求收藏。首頁如保留進度提醒，僅導向該角色詳情，不直接開第二套覺醒操作。

採有引導文案的狀態式 wizard：每頁一個主要問題、一個主要行動。條件來自存檔與服務，沒有玩家自填的資格確認，也不需要聊天模型。未完成條件停在當下；完成後重讀狀態並顯示下一步，已完成條件直接略過。「全部條件與目前進度」預設收合，避免再變成一張長表單。

## 步驟與核對來源

| 狀態 | 主要問題／行動 | 通過的證據 |
| --- | --- | --- |
| 尚未收藏 | 先和這位夥伴相遇，好嗎？前往劍隱山河召喚 | collection 擁有此角色；召喚與邀請沿用既有成本與流程 |
| 親密度不足 | 先讓你們更熟悉彼此，好嗎？前往此角色養成 | 真正 bondLevel ≥ 5，不採舊派遣專長下限 |
| 最後故事未领獎 | 聽聽牠最後一段同行故事，好嗎？開啟 Lv.5 同行故事 | bondJourney 該角色 chapters[5].claimedAt；讀過未領獎仍不通過 |
| 可開始 | 願意和牠接下這個約定嗎？接下守諾試煉 | startPetAwakening 成功，才開始計入新事件 |
| 日常未滿 | 今天，先一起完成一件小事？前往今日任務／習慣 | eventKeys 三筆新完成，沿用去重與開始／恢復時間規則 |
| 古道未完成 | 一起走一趟雲棧古道，好嗎？前往派遣 | 接下後出發、cloudrest_trail、此角色參隊且已領獎 |
| 缺食物 | 準備一份行旅糰，好嗎？前往工坊製作 | inventory.item_pine_trail_riceball ≥ 1；保留信物与進度 |
| 全部齊備 | 準備與牠共赴此約了嗎？完成覺醒 | 再驗擁有、Lv.5、故事獎勵、ready、信物及食物；清楚列出信物一枚＋食物一份 |
| 完成 | 牠以新的姿態，繼續與你同行 | awakenedAt 已保存，開放形態、故事、稱號與回應 |

日常與派遣是並行條件，不要求先日常再派遣。在日常頁提供次要「也可以先去古道同行」，派遣先完成後仍返回缺少的日常。試煉兩項皆滿時由既有服務自動給信物，沒有額外「領取信物」人工作業。ready 不再佔 activePetId，可開始其他夥伴試煉。

## 離開、暫停、返回與異常

- 「稍後繼續」只退出頁面，活動中的試煉仍計入。重新進入直接顯示下一個缺少條件，不重播開場訪談。
- 「暫停試煉」停止新事件計入並保留已完成進度；重新進入先問是否恢復。恢復只計入恢復後的新完成。
- 另一位夥伴正在試煉時，先問是否暫停另一位並切換。正式實作依序呼叫現有暫停與開始服務；若中途失敗，顯示實際狀態，不宣稱切換成功，不刪除任一角色進度。
- 從日常、故事、養成、工坊、派遣返回時，重讀相關狀態並同步試煉，再求出下一步；頁面重新聚焦亦刷新。目的頁尚未完成，不推進。
- 事件先後、暫停、去重、歷史完成與派遣條件全沿用現有服務，不新增資料模型、不改備份格式。wizard 頁碼由狀態推導，不持久化第二份進度。
- 最後確認重新核對服務端交易條件。跨分頁已消耗或資料不符，顯示可行的下一步；讀取失敗保留原資料並提供重試，不把失敗顯示為零進度。

沿用 `playAwakeningScene`、`pet-awakening.css` 與二十位現有圖片。UR 約五秒、其他約三秒，減少動態約 0.6 秒；可略過和重播。正式流程必須先由 `awakenPet` 在單一交易中成功扣食物、消耗信物、保存覺醒，再播放演出，不能等動畫結束才寫入。關頁、略過或播放失敗不撤回已成功的覺醒；重新進入按真實存檔展示完成。

完成前只展示初遇相，不先露出覺醒卡面。完成後預設覺醒相，按角色保留雙形態偏好，沿用圖鑑／詳情／首頁的 portrait 套用。重播只有視覺，不再次扣材料。稱號不自動取代玩家已裝備稱號。

## 檢視方式與實際限制

`devtools/awakening-wizard-review.html` 是可操作的代表切片：二十位可選角色、八種起始情境、既有動畫與雙形態。目的頁以清楚標示的「示範完成」模擬返回，不嵌入或操作正式 App。狀態只在記憶體，頁面重載回到示範起始值；原型中的關閉、重進與暫停保留本次操作。正式實作的持久化由既有服務承接。

啟動 `node devtools/onboarding-browser-server.mjs 0`，使用輸出的 loopback origin 開啟 `/devtools/awakening-wizard-review.html`。原型只 fetch catalog 及圖檔，沒有開 IndexedDB、沒有註冊 SW、沒有呼叫召喚／交易 API。
