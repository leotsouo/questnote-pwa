# 劍隱山河覺醒系統：已定案規格與實作

2026-10-02：覺醒與雲棧古道地圖已隨 V3.5.5 正式發布，見[發布紀錄](../reports/awakening-implementation/production-release.md)。後續依使用者要求加入教學與初遇預覽，V3.5.6 候選待審閱；不沿用上一整包的發布授權。本文件獨立維護，不加入新卡池 SOP。原始討論：[設計草案](pet-awakening-system.md)。

## 卡圖

V3.5.3 至 V3.5.5 使用第三版卡圖呈現未覺醒與抽卡角色。依後續「保留覺醒驚喜」要求，V3.5.6 候選改以[盤點的前版候選](../reports/awakening-discussion/art-inventory.json)呈現卡池預覽、單抽／十連演出及結果、未覺醒的圖鑑／詳情／原圖／首頁陪伴；未獲得預覽也使用初遇圖。圖片失敗先回到初遇原圖，避免縮圖失敗提前露出覺醒造型。既有未覺醒角色直接採此呈現，不變更持久化資料。已覺醒角色保留逐隻形態偏好，預設覺醒相；重複抽到同角色仍呈現初遇相。其他卡池不受影響。每隻另有故事、稱號、三則陪伴回應與演出，敘事延伸本池原創 Lore，不宣稱是金庸原著事件。

`pet_ur17` 的覺醒相使用已核准的新張口朱息造型；V3.5.6 候選的初遇呈現同樣改為前版候選。新圖強調厚重坐鎮、金眼、天然朱金脈紋，以及朱息退霧後留下安全通路；不增加龜殼或蛇身。閉口候選、前版與第三版均保留。[新圖來源與雜湊](../content/awakening/swordwild-shanhe/awakened-art.json)、[修訂歷史](../content/awakening/swordwild-shanhe/art-history.jsonl) 保留原核准，不改寫歷史。

## 流程及交易

1. 已擁有、親密度Lv.5，並已領取該角色Lv.5同行故事，才能接下試煉。既有達標角色直接承接。
2. 接下後完成三筆新的任務／習慣，以及一次該角色參隊的雲棧古道派遣領獎。派遣須在接下後出發，隊長或隊員均可。
3. 同時只進行一隻；暫停、換角、恢復保留進度，暫停期間不計入。原同行約定可並行。
4. 試煉完成保證取得角色信物一枚，進入等待儀式狀態，可以接下一隻試煉。
5. 儀式消耗「信物一枚＋松香行旅糰一份」，所有稀有度相同，不扣親密度、星塵或碎片，不改機率、保底與派遣收益。材料不足保留信物與進度，提供工坊入口。

角色詳情提供門檻、進度、材料與獎勵預覽；首頁顯示目前、待儀式或暫停的摘要。稱號由既有管理介面裝備，不自動替換玩家選擇。

現有IndexedDB `meta` store保存 `petAwakening`，沒有增加store。`schemaVersion: 1`，包含 `byPet`、`activePetId`、`usedEventKeys`；逐隻保存開始／觀察時間、三筆完成、派遣ID、信物發给與消耗時間、覺醒時間與形態。

任務以 `task:<id>`、習慣以 `habit:<id>:<date>`、派遣以 `expedition:<id>` 去重。同一完成只推進一隻；已計入後撤銷不倒扣，重新完成不重複。開始／恢復時排除既有完成與已領獎紀錄。任務／習慣寫入與進度同一交易，派遣領獎亦同步記錄；重載核對持久化完成紀錄。

儀式單一交易檢查門檻、扣食物、消耗信物並記錄覺醒，成功後才播動畫。跨分頁只成功一次，交易中斷不留下單邊扣物品。稱號由已覺醒紀錄衍生，不會被另一筆成就存檔覆寫而失去。

## 形態及演出

形態按角色保存，套用圖鑑列表、詳情、原圖與首頁陪伴。已覺醒圖片失敗使用第三版，保留偏好；未覺醒使用初遇原圖。符合門檻的已擁有角色預載雙形態卡片與舞台WebP，原圖按需載入。抽卡計算使用原 catalog，結果提交成功後以展示副本套用初遇圖片，不修改 catalog、抽卡交易或稀有度。

卡池「卡池詳情」旁提供星芒圖示、山河青金配色的「羈絆覺醒」按鈕，預設收合，點擊切換展開／收合，`aria-expanded` 與內容同步；切換卡池重置收合，其他卡池不顯示此按鈕。「更多 → 使用教學」與此區共用覺醒三步說明：Lv.5 與最後同行故事獎勵、接下後三筆日常及新出發古道派遣領獎、信物與一份松香行旅糰。卡池入口可直接跳至完整教學並聚焦，教學提供圖鑑與工坊入口，不需先擁有或達標。文字明示可選、不改戰力收益，並保留新造型的驚喜，不在教學展示覺醒圖片。

## 備份與發布

備份envelope維持版本2，覺醒資料內部版本1。3.5.4及以前完整備份缺欄位時補入未覺醒值；3.5.5起要求該欄位。新版可還原進度、信物、時間、形態與已裝備稱號；未知版本、重複事件、矛盾或錯誤欄位在替換前拒絕，不默默丟資料。
