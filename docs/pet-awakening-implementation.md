# 劍隱山河覺醒系統：已定案規格與實作

2026-10-02：依使用者定案實作；功能隔離驗收通過，尚未正式發布。覺醒與雲棧古道地圖重製以同一整包取得人工驗收及明確「可以發布」後發布。本文件獨立維護，不加入新卡池 SOP。原始討論：[設計草案](pet-awakening-system.md)。

## 卡圖

V3.5.3已使用第三版卡圖，但沒有覺醒功能。既有玩家仍直接看到第三版，抽卡也繼續使用該圖。二十隻覺醒後開放「初遇／覺醒」選擇，初遇使用 [盤點的前版候選](../reports/awakening-discussion/art-inventory.json)，覺醒預設使用第三版；每隻另外取得故事、稱號、三則陪伴回應與演出。敘事延伸本池原創 Lore，不宣稱是金庸原著事件。

本輪使用者指出鎮嶺蛤變化不足，要求重新生成並張嘴。因此 `pet_ur17` 的覺醒相使用新張口朱息造型，未覺醒及抽卡保留第三版。新圖強調厚重坐鎮、金眼、天然朱金脈紋，以及朱息退霧後留下安全通路；不增加龜殼或蛇身。閉口候選、前版與第三版均保留。[新圖來源與雜湊](../content/awakening/swordwild-shanhe/awakened-art.json)、[修訂歷史](../content/awakening/swordwild-shanhe/art-history.jsonl) 記錄新用途待整包人工驗收，不改寫原核准。

## 流程及交易

1. 已擁有、親密度Lv.5，並已領取該角色Lv.5同行故事，才能接下試煉。既有達標角色直接承接。
2. 接下後完成三筆新的任務／習慣，以及一次該角色參隊的雲棧古道派遣領獎。派遣須在接下後出發，隊長或隊員均可。
3. 同時只進行一隻；暫停、換角、恢復保留進度，暫停期間不計入。原同行約定可並行。
4. 試煉完成保證取得角色信物一枚，進入等待儀式狀態，可以接下一隻試煉。
5. 儀式消耗「信物一枚＋松香行旅糰一份」，所有稀有度相同，不扣親密度、星塵或碎片，不改機率、保底與派遣收益。材料不足保留信物與進度，提供工坊入口。

角色詳情提供門檻、進度、材料與獎勵預覽；首頁顯示目前、待儀式或暫停的摘要。稱號由既有管理介面裝備，不自動替換玩家選擇。

現有IndexedDB `meta` store保存 `petAwakening`，沒有增加store。`schemaVersion: 1`，包含 `byPet`、`activePetId`、`usedEventKeys`；逐隻保存開始／觀察時間、三筆完成、派遣ID、信物發给與消耗時間、覺醒時間與形態。

任務以 `task:<id>`、習慣以 `habit:<id>:<date>`、派遣以 `expedition:<id>` 去重。同一完成只推進一隻；已計入後撤銷不倒扣，重新完成不重複。開始／恢復時排除既有完成與已領獎紀錄。任務／習慣寫入與進度同一交易，派遣領獎亦同步記錄；重載核對持久化完成紀錄。

儀式單一交易檢查門檻、扣食物、消耗信物並記錄覺醒，成功後才播動畫。跨分頁只成功一次，交易中斷不留下單邊扣物品。稱號由已覺醒紀錄衍生，不會被另一筆成就存檔覆寫而失去。
