# V3.5.1 親密度更新計畫

## 目標

讓提升親密度能帶來角色專屬故事與日常同行用途。依討論採用可選回應、共同主線結局、既有任務／習慣目標；沒有錯誤答案、逾期懲罰或親密度衰減。

## 實作

- 保留 Lv.1～5、經驗門檻及既有解鎖。所有目前 96 位角色各有 Lv.2～5 四章故事、兩個對話回應、同行邀請、完成後續與一件專屬紀念物。新角色缺少故事時明確提示內容尚未收錄，不冒用通用故事。
- 依序閱讀章節、選擇回應，再選一項未完成任務（完成 1 次）或有效習慣（依章節累積 1／2／3／5 個不同日期的打卡）。每位角色的章節依序完成，玩家同時只有一份同行約定。
- 章節獎勵為固定 30／50／70／100 星塵，每角色每章限一次，不依稀有度變動。Lv.5 完成後可重複日常同行，連結任務或習慣完成 1 次，所有角色合計每日限領 20 星塵一次。
- 約定可暫停、繼續、更換目標或結束；沒有期限。只計入接受／繼續後的新完成，已計入的進度不倒扣；同一任務或同一天的同一習慣不能重複計入任何約定。完成但尚未領取的約定不可被覆蓋。
- 首頁提供故事／同行入口和目前進度，角色詳情展示章節、解鎖用途與紀念物；故事可回看並重播另一個回應，回看不改變已保存的初次選擇，也不再發獎勵。紀念物可選擇展示在陪伴頁及營地。
- 新增獨立故事目錄與 `bondJourney` meta 紀錄，保留舊版資料。所有獎勵與領取紀錄以同一 IndexedDB 交易提交；備份匯出／匯入包含進度、約定、防重複紀錄和展示選擇。
- 版本與 SW 同步至 3.5.1，預快取故事目錄和新增模組；建立本機可審閱成果，正式部署循既有 immutable artifact 流程另行記錄。
