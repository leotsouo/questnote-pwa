# 三套 QuestNote：內部 Jury Review

這是設計角度的定性檢視，不是正式評審、獲獎預測或假分數。現況依實際 Before，升級依真實 runtime 截圖與測試。

公開依據：[Apple Design Awards 2025](https://developer.apple.com/design/awards/2025/) 的視覺／互動／愉悅／包容性案例；[iF 評審](https://ifdesign.com/en/if-design-award-and-jury) 的 idea、form、function、differentiation；[Red Dot jury](https://www.red-dot.org/bcd/red-dot-jury) 的 idea、form、impact。本輪只套用這些觀看角度，不把任何奖项误认成一种固定风格。

| Lens | Before 的距離 | 本輪判斷與保留限制 |
|---|---|---|
| Apple / Visuals & graphics | 深色／甜美首屏资源和重卡片先于角色；暮光有方向但方图重叠 | 三套各有完整光線／場景、同一角色辨識、克制 type hierarchy。明亮与暗色都用可量测的文字角色，角色原图保留。 |
| Apple / Interaction & delight | 完成收益与陪伴的连接较弱，部分操作密度像功能原型 | 同一完成操作同步今日进度、源奖励、亲密度与短暂角色反应；沒有裝飾用無限動態。驚喜來自陪伴，任務仍能快速完成。 |
| Apple / Inclusivity | emoji平台造型、颜色状态、密集小操作影响一致性 | 一套本机图示、44px主操作、真实状态文字、进度语意、导航current、键盘theme选择与reduced motion。浏览器证据不代替VoiceOver／原生触控实机测试。 |
| iF / Idea | Productivity、fantasy、companion容易被讀成分離模組 | 首页先同行、再行动、再共同成长，把三者放进一个顺序；保留原任务／数据／成长规则。 |
| iF / Form & function | 深色和甜美更像相同cards换palette | 星夜精準、晨光柔和、暮光紙頁；图片区、字型、表面、radius形成气氛，操作架构一致。 |
| iF / Differentiation | 原 Q icon 不能表达核心产品 | 同行星芽使用一个耳／芽／路的连续形；区别来自共同成长而非泛用清单或RPG武器。32px与真实手机mockup可检视。 |
| Red Dot / Idea | 幻兽有强角色资产，未充分成为產品心智 | 灰影幼狼同一身份处于三种環境；不存在角色的状態明确引導，不假裝拥有。 |
| Red Dot / Form | 大量框、粗字、emoji与重复CTA相互竞争 | 元件共享层级、local图示、语意tokens；强对比保留给任务／主要操作，幻想存在场景而非金框。 |
| Red Dot / Impact | 情绪集中在宠物图片，跨页感受容易消失 | 首页同行→图鉴收藏／培养→召唤相遇→冒险远行形成连贯世界；品牌icon跨theme固定。是否长期改善留存仍需要真实使用反馈，不能由漂亮截图推定。 |

三套各自的主要改善：星夜由资源仪表转为营地与今日目标；晨光由粉色版本转为照顾日常的花园；暮光保留手帐方向并修正人物／文字构图。现在是三种气氛的同一产品，而不是三个功能不同的 App。
