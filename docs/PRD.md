# QuestNote 角色收集與養成 — V3.6.0

本 PRD 記錄 2026-10-03 確定的相遇系統重構；正式部署仍以 release evidence 為準。詳細資料模型、原型先行審查與實作驗證見 [設計文件](encounter-fragments-design.md)、[原型審查](../reports/encounter-prototype-review.md)、[交付驗收](../reports/encounter-invitation-delivery.md)。

## 產品目標

第一次相遇加入收藏；每次重逢留下下一次可指定相遇的進度。召喚提供發現，指定邀請提供選擇；日常陪伴、同行故事與覺醒負責成長。角色仍是夥伴，名字優先於稱號與稀有度。

## 第一版範圍

N/R/SR/SSR/UR 重逢得到跨卡池共用的相遇碎片 1/2/5/10/20。SSR 指定邀請需 100，UR 需 200。只邀請尚未相遇的正式 active pool SSR/UR；尊重原本擴充／故事條件，角色預覽可說明尚未開放原因。

入口位於召喚頁，次於隨機召喚。角色畫廊無單卡標價或購買動作，選角色後才呈現費用；確認後原子扣款、加入收藏，直接播放所選角色原卡池的 SSR／UR 中獎登場演出，結束後回到邀請結果。跳過與重播不再次扣款，成功可直接設為同行。已擁有、尚未開放、餘額不足與寫入失敗均有可理解的狀態。

星級與角色專屬碎片停止成為活躍機制。探險專長為 max(親密度等級，舊玩家已取得能力下限)。既有親密度、約定、故事與覺醒條件不變；沒有補高親密度或提前完成故事。

## 資料與相容

舊碎片 1:1 加上累計升星投入 0/5/20/50/100，原子轉為共用餘額；角色逐筆標記與全局 migrationVersion 保證同份存檔不重發。一次性摘要提供總額及明細，新玩家不顯示歷史系統訊息。舊備份先轉換，再整份替換；新備份保留餘額、能力下限與收據。

目前資料屬本機 IndexedDB，沒有帳號或雲端同步。重新安裝後必須匯入完整備份才能帶回進度；本功能不能承諾不存在的帳號同步。

## 成功與後續評估

原有機率、30 抽 SSR+／100 抽 UR 保底、十連 SR 保障全部維持；邀請不修改任一 counter。貨幣與收藏必須一起成功或一起回復，同時邀請同一角色僅成功一次。

三主題、320px、放大文字、鍵盤、明確文字稀有度與 Reduced Motion 為驗收範圍；實機 VoiceOver 與 iPhone PWA 需裝置檢查。用內部 Apple/iF/Red Dot 角度檢視一致性，不宣稱官方認證。

第一版不增加追蹤服務、付費碎片、限時商店、折扣、抽數承諾、碎片加速或貨幣互換。100/200 價格後續只依實際自願回饋與收藏階段評估；模擬平均不放入 UI 作為保障。
