# 2. 世界觀核心

永眠花海存在兩個互相依存的循環階段：

```text
永眠期：
沉眠
保存
修補夢境
淨化惡夢
維持夜間秩序

晨醒期：
喚醒大地
恢復感官
開啟天空
恢復意志
使生命重新選擇方向
```

原有永眠花海的角色負責讓疲憊的生命安全沉睡、保存尚未完成的夢，以及維持夢境秩序。

晨醒花庭則負責判斷沉睡何時應當結束，使已準備好的生命重新回到清醒、選擇與行動之中。

四隻追加角色形成完整的甦醒流程：

```text
第一階段｜曉露花蝟
喚醒地面、身體與溫度。

第二階段｜晨鈴花雀
喚醒感官、聽覺與意識。

第三階段｜曦幕雲鶴
開啟夢幕，使天空與外部世界重新進入花庭。

第四階段｜曙綻花后兔
完成意志、選擇與真正行動的甦醒。
```

一句話總結：

> 曉露花蝟讓身體醒來，晨鈴花雀讓感官醒來，曦幕雲鶴讓世界重新抵達，曙綻花后兔則讓生命決定真正起身。

# 4. R｜曉露花蝟

```text
正式名稱：曉露花蝟
正式稱號：晨露啟花者
稀有度：R
原型：刺蝟
甦醒階段：地面、身體與溫度
```

## 一句話定位

> 牠以背部凝聚的晨露喚醒低矮花叢，讓永眠花海的第一批晨花沿著足跡綻放。

## 世界觀職能

曉露花蝟是晨醒循環中最早開始活動的生物。

牠在夜色尚未完全退去時離開棲地，將凝聚於背部花芽、嫩葉與柔刺上的露水帶往花海低地。

晨露滲入夢土後：

```text
地表逐漸恢復溫度
低矮植物開始舒展
沉睡生命恢復體溫
第一批晨花開始綻放
```

牠象徵的是最基礎、最實際的甦醒：

```text
呼吸恢復
四肢活動
身體重新感受到大地
從第一步開始新的一天
```

## 個性

```text
勤快
樂觀
實際
不怕重複工作
具有清晨剛甦醒的活力
```

## 定版圖片特徵

```text
暖月白小型刺蝟
背部覆蓋淡粉花苞、嫩葉與柔化短刺

快步通過濕潤花徑
```

# 7. UR｜曙綻花后兔

```text
正式名稱：曙綻花后兔
正式稱號：甦醒花庭的晨曦主人
稀有度：UR
原型：大型夢境垂耳兔
性別定位：女性
身份：晨醒花庭主人
關係：永眠花皇兔的對等伴侶
甦醒階段：意志、選擇與真正行動
```

## 一句話定位

> 她掌管甦醒、花開與重新行動，會在最適當的時刻結束長夢，讓生命重新選擇前方的方向。

## 世界觀職能

曙綻花后兔不是讓所有生命立刻醒來。

她真正掌管的是：

> 判斷一個生命是否已準備好甦醒。

在她完成判定前：

```text
地面可能已經恢復溫度
感官可能已經重新運作
晨光也可能已經進入花庭
```

但只有她將選擇權重新交還給沉睡者後，生命才會真正從「受到保護」轉回「能夠選擇與行動」。

她掌管：

```text
甦醒
生長
晨光
花開
行動
重新選擇方向
```

## 「花后」的正式定義

「花后」不是附屬於花皇兔的王后稱號。

它是永眠花海對：

```text
花開與甦醒循環主人
```

的古老稱謂。

曙綻花后兔與永眠花皇兔權柄對等、地位對等。

## 個性

```text
果決
寬和
清醒
成熟
克制
具有穩定而明亮的生命力
```

她不責備尚未準備好醒來的生命，也不會將沉睡視為軟弱。

但當她判斷甦醒時機成熟後，便不會容許生命用猶豫偽裝成休息。

## 定版圖片特徵

```text
大型暖月白與成熟晨曦玫瑰色垂耳兔
厚實端坐姿態
雙耳向兩側自然下垂並向外舒展
雙眼完全睜開
瞳色帶琉璃青、金色與玫瑰色反光
頭後為完整圓形晨花花環
胸前為大型多層晨醒花束與晨露晶飾
背景為粉金晨曦、古老花庭、鏡池與盛開花海
```

# 8. 雙主人完整關係

## 權柄對照

| 永眠花皇兔 | 曙綻花后兔 |
|---|---|
| 沉睡花庭的古老主人 | 甦醒花庭的晨曦主人 |
| 沉眠 | 甦醒 |
| 保存 | 生長 |
| 夜晚 | 晨光 |
| 休息 | 行動 |
| 讓疲憊生命安全停止 | 讓準備好的生命重新前行 |
| 夢潮向內收束 | 夢潮向外展開 |
| 花環收合 | 花環綻放 |

## 關係核心

永眠花皇兔讓過度活躍的夢境學會閉合；曙綻花后兔則讓被保存的夢在適當時刻結束。

```text
永眠花皇兔：
接住疲憊，使生命可以安全停止。

曙綻花后兔：
判斷時機，使生命可以重新開始。
```

沉眠不是失敗，甦醒也不是對沉眠的否定。

兩者共同構成完整的夢境循環。

## 為什麼無法長時間同時清醒

```text
永眠花皇兔清醒時：
花庭夢潮向內收束。

曙綻花后兔清醒時：
花庭夢潮向外展開。
```

若兩位主人長時間同時清醒：

```text
花苞會同時閉合與綻放
鏡池會同時保存與釋放記憶
夢幕無法完全閉合或開啟
花海居民會停留在半夢半醒狀態
```

因此牠們主動接受權柄輪替，而不是被命運強迫分離。

## 代表性交接動作

> 兩位主人各將一隻前足放在同一朵雙相月皇花兩側，兩個花環短暫重疊成完整圓環；轉身交錯時，彼此的垂耳輕輕擦過。

這個動作象徵：

```text
權柄對等
彼此信任
交接而非告別
短暫重逢
長久相伴
```

## 共同信物

```text
雙相月皇花
雙相花環
```

## 私下稱呼

```text
永眠花皇兔稱曙綻花后兔：曦庭
曙綻花后兔稱永眠花皇兔：眠庭
```

「曦庭」保留為兩位主人之間的伴侶專屬稱呼。

曙綻花后兔允許契約者使用的專屬稱呼為：

```text
朝華
```

# 14. 十連解鎖邊界

解鎖條件只能在一次完整抽卡交易結束後判定。

例如：

```text
抽卡前 lifetimeDraws：15
執行十連
```

本次十連的 10 個結果仍必須全部使用原本的 12 隻候選。

交易完成後：

```text
lifetimeDraws：25
晨醒花庭解鎖
```

從下一次抽卡開始，才使用 16 隻候選。

禁止在十連的第 6 抽中途改變候選池。

# 18. 晨醒花庭解鎖動畫

正式分鏡：

```text
1. 第二十道召喚光落入鏡池。
2. 鏡池波紋逐漸停止。
3. 一滴蜜桃金晨露落在閉合花苞上。
4. 夜藍月光轉為霧紫、晨曦玫瑰與淡金。
5. 水面映出閉著眼睛的永眠花皇兔。
6. 倒影逐漸轉為曙綻花后兔。
7. 曙綻花后兔在倒影中睜開眼睛。
8. 她從鏡池倒影踏入真實花庭。
9. 兩位主人以雙相月皇花完成權柄交接。
10. 曦幕雲鶴展開夢幕，迎入晨光。
11. 晨鈴花雀鳴唱，枝冠花苞依序開放。
12. 曉露花蝟抖落晨露，地面花朵沿足跡盛開。
13. 四隻角色剪影依 R → SR → SSR → UR 亮起。
14. 顯示「沉眠有歸，甦醒有時。」
15. 顯示「晨醒花庭已解鎖」。
16. 曉露花蝟留在前景，顯示固定取得結果。
```

正式解鎖短句：

> 沉眠有歸，甦醒有時。

正式解鎖標題：

```text
晨醒花庭已解鎖
```

動畫只負責顯示，不負責：

```text
抽卡
扣除星塵
變更保底
發放獎勵
修改候選
```

解鎖與固定獎勵必須在動畫播放前完成。

# 19. 動畫觸發順序

門檻跨越時的正確順序：

```text
正式召喚動畫
→ 顯示本次單抽／十連結果
```

不得讓解鎖動畫搶在本次抽卡結果之前出現。

```text
解鎖狀態保留
固定獎勵不得重複發放
下一次進入永眠花海時補播動畫
```
