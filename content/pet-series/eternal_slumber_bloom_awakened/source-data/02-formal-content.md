# QuestNote｜晨醒花庭 4 隻角色正式文案

本文件收錄晨醒花庭追加 4 隻角色已通過並鎖定的正式文案。

包含：

```text
title
personality
loreElement
description
lore
dialogues
bondUnlocks
```

注意：

```text
loreElement 是交接與 Builder Workspace 使用的辨識欄位。

正式寫入 pets-lore.json 時：
loreElement 必須轉換為 element。

name 只用於角色對照，
不應額外加入正式 pets-lore.json schema。
```

角色名稱、稀有度、稱號、圖片與文案均不得重新修改。

# 完整性檢查

```text
角色數量：4

正式名稱：4／4
title：4／4
personality：每隻 2 個
loreElement：4／4
description：每隻 2 句
Lore：4／4

normal：每隻 5 句
urgent：每隻 5 句
important：每隻 5 句
praise：每隻 5 句
idle：每隻 3 句
bondUp：每隻 2 句
summon：每隻 1 句

bondUnlocks：
每隻均包含 2、3、4、5
```

Lv.4 專屬稱呼：

```text
曉露花蝟：露芽
晨鈴花雀：晨羽
曦幕雲鶴：雲帷
曙綻花后兔：朝華
```

伴侶專屬稱呼：

```text
永眠花皇兔稱曙綻花后兔：曦庭
曙綻花后兔稱永眠花皇兔：眠庭
```

所有內容均未提及：

```text
20 抽
免費贈送
保底
星塵
卡池機制
程式系統
```
